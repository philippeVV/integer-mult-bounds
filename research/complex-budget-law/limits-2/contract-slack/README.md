# Contract slack (expL8, expXW, expXV): which premises of "Tanner code + frames" are forced, and what the unforced ones buy

Status: short lemmas, exact small checks and numerical searches, author-checked, LOCAL-ONLY until published. No κ claim.
Base: main `0fdd7d82`. Multipliers are over κ = 0.0017. Upstream file:line citations are at `0fdd7d82`.

## Verdict

| Item | Value |
|---|---|
| Question (expL8) | which hypotheses of the frame contract (H1–H8 below) are forced by the TM model, and which are choices that no closure covers? |
| **Lemma N1** (gates must be linear) | a pointwise gate that commutes with a non-monomial frame D is additive and Q(i)-homogeneous on the frame group generated by C = aI + bX (a = (1+i)/2, b = (1−i)/2), hence C-linear by continuity. Nonlinear gates are compatible only with monomial frames (permutation and sign labels), where the cut lemma of upstream `research/nonlinear-frame-cut-bound` gives s ≥ Wm. **Closed: nonlinear, carry, rounding and comparison gates** |
| **Lemma B1** (affine border families) | in the additive rank contract, M_v(t) = t⁻¹A_v + B_v with an exact endpoint for all t forces ΔA = 0 on the endpoints, B exact, and rank(ΔA + tΔB) ≥ rank ΔB for generic t: B is never worse. Bounded families M = X + tY + … reduce to t = 0 by lower semicontinuity of rank |
| **Lemma B2** (border gains only through t⁻¹) | Laurent families can beat their finite part (t⁻¹(u + tv)(w + tz)ᵀ has rank 1, its t⁰ part rank 2: the Bini phenomenon), but **every repo screen survives**: rank(endpoint(t)) ≤ s and the limit has rank Wm; cut and flow screens are graph statements; Tanner dimension is upper semicontinuous; Boot is field-free |
| **Lemma B3** (border frames cost precision) | complex supplier, t = 2^-q: the O(t) error must reach 2^-p, so q ≥ p; t^-K entries force p_child ≥ (K+1)p at every level, a factor ≥ 2 per level, fatal by the overhead law unless the per-level gain exceeds ×2 (today ≈ 1 + 0.7%). **Closed: approximate/border frames, ε-rank of frame differences, low-rank-plus-small-error frames, precision-split child calls, the tolerance of Gaussian resampling** (×1.0; only a bounded number of top levels can use them) |
| ε-coding gaps | zero-error and vanishing-error rates coincide for linear network codes; in general the question is the open edge-removal problem (Langberg–Effros 2011). Not a lever |
| **Lemma G** (commutant) | all 512 phase frames C_U at m = 3 commute with every translation X_v, C_v = aI + bX_v, and the commutant of the family is exactly the 2^m-dim translation algebra C[F₂^m]: gates with translation terms are automatically frame-compatible |
| Unforced premises (expL8, ranked) | (1) the **MDS clause** of Problem X (a gate needs only its scheduled in/out halves to be information sets); (2) **reversibility with dirty restoration** (zero scratch, fan-out, free erasure); (3) **gates with translation terms** (Lemma G). Planning ceiling for each: the conditional Problem-X values ×59 (a = 1/9) … ×142 (s = ¼) |
| **(2) erasure is priced as a local pass (expXW)** | allocating or erasing a register costs one pass, O(Z·V/W) per node, which sits in the O((eK)^τ + 1) term of the recurrence (upstream `05-layers.tex:645-656`) and costs 0 in the exponent; zero-born edges need no source frame (D·0 = 0) and erased edges no sink frame, so both cost 0. Precedent: upstream's copied-centers lemma (copy/transform/read/discard). This drops the finite contract's all-role endpoint for scratch; it is an interface extension, not an upstream lemma |
| **(2) mixed rates are not a lever (expXW)** | with dangling zero sources and erasers, the local code at v is the graph of a linear map with k_v = in-degree, so Σk_v = E for **every** rate profile (the naive dimension is 0 and s is pure excess), the bootstrap theorem holds verbatim for MDS codes of any dimension, schedulable ⇒ dim C = \|R\| = Boot for any orientation, and the threshold s ≥ 1/(1+(g−1)^{1−a}) does not depend on the rates. On PG(2,q), q ≤ 9, **no profile beats the balanced half-rate Boot** (best 166/910 = 0.1824 < 0.1930); unbalanced profiles lose heavily, and a hill-climb over orientations returns to balance |
| **(2) the live lead: full PG(2,16) (expXW)** | non-reversible gates can be 8→9 / 9→8, so odd-degree planes enter without matching deletion or C/J lanes. Full PG(2,16) with [17,8]/[17,9] codes: the Hermitian F₁₆ code has dim 900 (expNC), Boot ∈ [900, 907], **s = 900/4641 = 0.19392 > 0.19300**: not excluded at a = 1/9 (reversible PG(2,16)−M: 784/4368 = 0.1795). Bit-side dimension ceiling a = 0.1148, κ = 0.103, **×60.6** (Boot ceiling ×63.4). Needs a causal schedule with \|R\| ≤ 906 (best found by expXW: 1209), frames, and a complex side. **Follow-up expXX closes this lead for the Hermitian route (`../full-pg16/`)**: best \|R\| = 909, the completion fails (an exact schedule needs \|R\| = 900), and the complex Markov cap on this host is 0.18147 < 0.193 |
| **(1) dropping MDS closes at ×1.0 (expXV)** | on PG(2,5) and PG(2,7), with the barrier only on the two scheduled minors per code, every apparent hit above E/6 (r = 31–37 on PG(2,5), 77–80 on PG(2,7)) is a degeneration: the common-gauge in/out margin collapses to e^-23 … e^-43 and the spectrum of K has no converged kernel; holding the common-gauge barrier fixed collapses them (dim ≈ 28 < 31, ≈ 65 < 76). Stable non-degenerate values: about 13–22 on PG(2,5) and 32–50 on PG(2,7), i.e. 0.6–0.85·E/6. The extra dimension comes from gates decomposing toward routing (130 of 153 blocks are 1×1 pass-throughs at r = 32), and routing has dim ≤ E/girth |
| **Structural point (expXV)** | an exact schedule with char-0 gates (dim = \|R\|, the code realises T = I on the back arcs) **is its own char-0 monomial realisation**, so Z = blockdiag(I) and s ≥ Wm for every rank-metric (Q/C-rank) frame. A positive-nullity screen on a char-0 schedule can only come from the phase-frame cost (F₂ polar rank) through GRS-F₂, i.e. from an incidence that is not char-2 realisable. And the flow screen F_* < W is automatic at girth 6 once S > E/6 (sessions have distance ≥ 5, F_* ≤ (E − S)/5), so it is never decisive there |
| (3) translation-term gates | not run. Likely ×1.0 asymptotically (each term is one butterfly direction); if the per-frequency networks decouple, a mixture of per-character Problem-X instances. P ≈ 2% (expL8) |

## The frame contract, reduced to its hypotheses (expL8)

| # | hypothesis | forced? | evidence |
|---|---|---|---|
| H1 | gates linear | **yes**, whenever some frame is non-monomial | Lemma N1 |
| H2 | endpoint exact | **yes**, recursively | Lemmas B1–B3 |
| H3 | network data-oblivious | yes, up to ×O(1) padding, and then κ ≤ η* (coding-gap transfer, #2838) | AFKL transfer |
| H4 | same frame on every column, one child per slot | no, but relaxing it gives a child-rank histogram, i.e. a mixture | budget law; `../../limits-1/single-letter/` Thm 1 |
| H5 | children are the same problem | no, but coupled suppliers and nesting are ×1.00 | STEP-CHANGE-MAP |
| H6 | gates invertible on W roles; all roles start dirty and are restored | **no** | expXW (above) |
| H7 | local codes MDS | **no** | expXV (above) |
| H8 | gate coefficients are constants | **no** | Lemma G |

## expXW: mixed-rate details (R1–R5) and Boot over rate profiles

- **R1** dangling zero-source and erased edges are free and dimension-neutral. **R2** Σ_v k_v = E for every profile; the rate
  profile is exactly an in-degree vector; WLOG 1 ≤ k_v ≤ d_v − 1. **R3** a = 1 − ln((E−S)/S)/ln(g−1), threshold independent
  of the rates (planning ceiling; telescoping and flow screens still hold). **R4** dim C ≤ Boot(Γ, k) = min_σ Σ(k_v − j_v)^+
  for MDS codes of any dimension; in a causal schedule \|R\| ≥ Boot; a schedule with \|R\| = dim + c completes with c zero-born
  and c erased edges to s_c = (dim − c)/(E − 2c) (expXX finds that this completion fails for the PG(2,16) Hermitian code,
  `../full-pg16/`). **R5** Boot(k) = Boot(d − k); Boot(k) ≤ FAS of any orientation with in-degrees k; class-uniform (t, d−t)
  profiles have Boot ≤ N·min(t, d−t); Boot is not concave in k, so balance had to be checked numerically.
- Greedy upper bounds (60 restarts), threshold at a = 1/9, g = 6: 0.1930.

## expXV: method and key rows

Orientation: order σ from expXP's best Boot key plus restarts, Eulerian k-in/k-out orientation with the fewest back arcs by
min-cost flow, hill-climbed on F: PG(2,5) cost 31, **F = \|R\| = 37**; PG(2,7) cost 80, **F = 96**. For in/out-invertible gates
W ≅ ker(T − I) on C^R, so dim W ≤ F. Optimiser `cmds_io.py` (expXP's `cmds.py` with the barrier on log 2|det Q_in|² and
log 2|det Q_out|² only; `RAWBAR=0` own Barthe gauge, `RAWBAR=1` common canonical gauge).

of Lemma D (each code is fine alone; the P and L codes need relative edge scalings that diverge). Numerical evidence, not a proof.
